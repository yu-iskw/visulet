# V1 status

VisualDocument remains **version `"0"`**. Do not treat this tree as a
compatibility promise.

Experimental npm **0.1.0** (RFC 0003) is pre-1.0 only. See
`docs/releases/pre-1.0.md`.

RFC 0003 (`docs/rfcs/0003-rfc-0002-closeout.md`) is the closeout contract for
live measurement, MCP App binding, dogfood, and experimental 0.x prep. It does
**not** freeze v1.

RFC 0002 Phase 5 still requires a live stratified run. The current memo is
**blocked-on-credentials**. Until a live memo records GO against RFC 0002 §19
hypotheses, packages must not imply a stable API. Empirical IR breaks belong
in RFC 0004, not in RFC 0003.
