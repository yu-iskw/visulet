# @visulet/sdk

Semantic chart compiler. Assemble `ChartAssemblyInput` into Vega-Lite, ECharts,
Chart.js, Plotly, or Excel-native specs.

MCP pixel render covers Vega-Lite / ECharts / Chart.js only; Plotly and Excel
remain assemble-only. Catalog counts and theme ids: [docs/catalog.md](../../docs/catalog.md).
